The Google Workspace CLI supplies the account connection. Your assistant uses the authorized context for the workflow you request.

Bring the context your work needs.

cli-access is the Google account connection used by a personal desktop assistant. It supports authorized accounts and workflows run from your own workspace.

01 / CALENDAR

Plan around your day

Read calendar constraints so the assistant can prepare a useful agenda and suggest a next action.

02 / GMAIL

Find the conversation

Locate relevant email, retrieve context for a request, and prepare summaries or drafts.

03 / DRIVE

Work from the source

Find files and read the document context needed for the task you choose.

How the connection works.

Connect your account

Use Google’s browser-based sign-in and consent flow. Review the requested permissions before granting access.

Choose a workflow

Run a planning, search, summary, or drafting request in your desktop workspace. Selected context may be processed by the AI provider configured for that workflow.

Review the result

Check drafts against their sources. Actions that change account content follow the workspace’s user-instruction and approval rules.

Understand the access you grant.

The current connection requests Drive, Gmail modify, and Calendar permissions. These can permit content changes as well as reads. Workspace approval rules govern how the assistant uses that access.

Read about data use and storage
  • Google handles authentication; cli-access does not ask for your Google password.
  • Account connections run in the desktop integration. This information website does not connect to Google APIs.
  • You can revoke access in your Google Account at any time.
